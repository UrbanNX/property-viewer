@URBANNX/PROPERTY-VIEWER · 0.3.0 LOCAL

One package. Independent viewers.

Both panels import the same npm package. Load the sample, then change one panel's floor—the other stays independent.

The consumer code 
import { createPropertyViewer } from '@urbannx/property-viewer';

const viewer = createPropertyViewer({ container, labels, onEvent });
await viewer.load(await file.arrayBuffer());
viewer.command({ action: 'view', mode: 'floor', floor: 'Ground' });
// On unmount:
viewer.dispose();

Shared cad_scene and UrbanWave annotated GLB viewer. Synthetic samples, no backend, no uploads to a server. Views and wall opacity are transient and reset on reload. The narrow panel demonstrates container sizing, not a native Flutter WebView. Editor operations remain host-owned.
